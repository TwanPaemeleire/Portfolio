Self Learning Cars

Coming from game development, I wanted a project to learn Python and professional software practices with. I made a simulation in which cars teach themselves to drive, using sensors, a small neural network and evolution.

Current progress

  • Cars learning to lap a circuit
  • Simulation covered by automated tests
